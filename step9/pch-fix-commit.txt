[fix](build) Preserve OpenMP option groups in PCH builds

### What problem does this PR solve?

Problem Summary: With AppleClang and PCH enabled, FindOpenMP returns
-Xclang -fopenmp as a space-separated string. Passing this string directly
to compile options produces one argument and fails both PCH and ordinary
C++ compilation. Use SHELL groups in both affected locations so CMake
parses the flags into arguments while preserving their grouping.

### Release note

Fix OpenMP compiler argument handling in AppleClang PCH builds.
